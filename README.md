# Flight-Fare-Prediction
Flight Fare Prediction using Machine Learning with EDA, feature engineering, model comparison, and XGBoost hyperparameter tuning.


### A Machine Learning project to predict flight ticket prices based on factors such as airline, journey date, source, destination, route, duration, and number of stops.

## 🔍 Project Highlights

- Data Cleaning & EDA
- Feature Engineering
- Ordinal Encoding
- Model Comparison
- XGBoost Hyperparameter Tuning
- Actual vs Predicted Analysis


## 🤖 Models Used

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- XGBoost Regressor

## 🛠️ Technologies

Python | Pandas | NumPy | Matplotlib | Seaborn | Scikit-learn | XGBoost
